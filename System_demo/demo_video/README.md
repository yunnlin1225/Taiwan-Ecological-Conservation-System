# 🎬 系統操作展示影片 (System Demo Video)

本影片展示「台灣生態保育資訊系統」的實際操作流程，用於呈現 Web 前端、PHP 後端與 MySQL 資料庫整合後的系統功能與操作結果。

## 📌 展示內容

影片主要展示以下系統功能：

- 👤 會員註冊、登入與會員資料管理
- 🐾 生態動物資料瀏覽與條件篩選
- 🔍 生態物種關鍵字搜尋
- 💬 生態留言板新增、排序與刪除
- 📊 物種資料統計與視覺化分析
- 🌿 系統首頁與各功能頁面操作

## 🛠️ 系統技術

系統使用 **HTML、JavaScript、PHP、MySQL** 進行開發，並透過 **Apache Web Server** 建立網站執行環境，完成前端介面、後端功能與資料庫之間的整合。
